# Práctica 8: Azure Static Web Apps

Aplicación web estática creada con HTML, CSS y JavaScript para demostrar un despliegue automático desde GitHub mediante Azure Static Web Apps y GitHub Actions.

## Ejecución local

Abre `index.html` directamente en el navegador o utiliza la extensión Live Server de Visual Studio Code.

## Configuración en Azure

- Plan: Free
- Fuente: GitHub
- Rama: `main`
- Build preset: Custom
- App location: `/`
- API location: vacía
- Output location: vacía

## Archivos

- `index.html`: estructura de la aplicación.
- `styles.css`: diseño responsive.
- `script.js`: reloj, selección de región y prueba interactiva.
